Subscriber lookup

Look a device up by the payment code it shows in Settings (Device code): its subscriptions and whether their on-chain settlements landed. Refunds and cancels are done in the Stripe / App Store / Play console using the external_id. Move re-points a subscription at another device's code (a reinstall, a new phone) — the support override: no 30-day limit, and its renewals follow it from then on.
