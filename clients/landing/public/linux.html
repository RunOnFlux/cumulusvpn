CumulusVPN for Linux

The same calm app as on Mac and Windows: one Connect button, a kill switch, auto-reconnect and gateway failover, running quietly in your system tray. Free to use, no account, and it updates along with the rest of your system.

  • Ubuntu 24.04+
  • Debian 13+
  • Linux Mint 22+
  • Fedora 40+
  • 64-bit x86
  1. 1

    Install from our repository

    Open a terminal, paste the lines for your system and press Enter. This adds our signed repository, so updates arrive with your normal system updates.

    Ubuntu, Debian, Linux Mint 
    sudo wget -qO /etc/apt/keyrings/cumulusvpn.asc https://pkg.cumulusvpn.com/cumulusvpn.ascecho "deb [arch=amd64 signed-by=/etc/apt/keyrings/cumulusvpn.asc] https://pkg.cumulusvpn.com/deb stable main" | sudo tee /etc/apt/sources.list.d/cumulusvpn.list >/dev/nullsudo apt update && sudo apt install cumulus-vpn
    Fedora 
    sudo curl -fsSL -o /etc/yum.repos.d/cumulusvpn.repo https://pkg.cumulusvpn.com/rpm/cumulusvpn.reposudo dnf install cumulus-vpn

    On Fedora, dnf asks once whether to import the CumulusVPN key: check that it ends in D926 CF3B and answer y.

  2. 2

    Log out and back in

    The install adds you to the cumulusvpn group, which lets the app run the VPN without asking for your password. Your desktop picks that up at the next login, so log out and back in once (or restart).

    Installed it from App Center or GNOME Software instead? Add yourself with sudo usermod -aG cumulusvpn $USER, then log out and back in.

  3. 3

    Open CumulusVPN and connect

    Find CumulusVPN in your app menu and click the power button. Closing the window keeps you connected; on Ubuntu the app stays in the top bar.

    Fedora's desktop hides tray icons unless you add the AppIndicator extension. Without it, open CumulusVPN from the app menu again to bring the window back, and quit from Settings.

  • Updates come with your system updates (Software Updater, GNOME Software), or run sudo apt update && sudo apt upgrade / sudo dnf upgrade --refresh.
  • Requirements: a 64-bit x86 (x86-64) computer with systemd, running Ubuntu 24.04, Debian 13, Linux Mint 22, Fedora 40 or newer, or a distribution based on them. ARM isn't supported yet.
  • Prefer a package file? Every release on GitHub has the .deb and .rpm. Install it from a terminal (sudo apt install ./CumulusVPN_*_amd64.deb or sudo dnf install ./CumulusVPN-*.x86_64.rpm); it adds the same repository, so it keeps updating.
  • Signed: packages and repository are signed with our key 707A 0C78 FE68 0285 3F89 60A7 7DCB A649 D926 CF3B, and every release has signed checksums.
  • Uninstall: sudo apt remove cumulus-vpn or sudo dnf remove cumulus-vpn. The VPN disconnects and your network goes back to normal.
  • On a router, a server or a device without a desktop? Use the web setup with the official WireGuard tools.
  • CumulusVPN is open source (MIT). Questions? We're here to help.
